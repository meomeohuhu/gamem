# Unity coursework map

The main Unity project is `SpaceExplore` and uses Unity `6000.6.5f1`.

The course practice assets are kept under `Assets/CourseLabs`:

- `LegacyAssets`: selected assets copied from the older projects before they were removed.
- `SlideAssets`: assets extracted from the supplied slides ZIP when the old projects did not contain the required material.

The editor command `SpaceExplore > Coursework > Build all practices` generates the practice scenes under `Assets/Scenes/Coursework` and appends them to Build Settings.

Weekly mapping:

- Weeks 1–2: Unity interface, transforms, GameObjects, Components, scenes, and Tilemap.
- Week 3: Rigidbody 2D, Collider 2D, Composite Collider, collision and trigger logging.
- Weeks 4–6: the existing Space Explorer project is the Lab 1/final project base.
- Week 7: Hero Knight animation controller and animation event practice.
- Week 8: TextMeshPro popup UI with Continue and Restart buttons.
